# 墨西哥西語學習 App 版本紀錄

> 📋 使用者要求：每次修改前必須先備份上一版本到 `versions/` 目錄，並建立修改說明檔。
>
> **生效日期**：2026-09-21

---

## 版本規則

- **MAJOR** (X.0.0)：架構變更（如單檔 → 多檔週次架構）
- **MINOR** (X.Y.0)：功能新增/大改（如新頁面、新互動模式）
- **PATCH** (X.Y.Z)：bug 修復、內容調整、UI 微调

---

## [v0.4.6] - 2026-09-21

### 修復
- **iPhone 離線 Script Error 真正原因**：之前錯誤猜測是 ES6 語法或 URL query string，真正問題是 `file://` 連結導航 + 巢狀 `<a>` 結構
- **改用純 HTML `<a href>` 連結**：index.html 完全重寫為靜態 HTML，零巢狀 `<a>`
- **URL hash 標誌化**：簡化為 `#d1` ~ `#d7`，week1.html 同時支援 localStorage 備援與 URL hash
- **week1.html 返回連結**：頂部加入「← 返回主頁」

## [v0.4.0] - 2026-09-21

### 新增
- **主頁 + 週次架構**：新增 `index.html` 主頁，顯示所有週次與每週 7 天預覽
- **週次頁面**：原 `index.html` 改名為 `week1.html`，保留完整 7 天課程
- **Day 精準跳轉**：主頁每個 Day 可點擊直達
- **完整內嵌字典 (DICT)**：80+ 詞條覆蓋所有例句單字
- **FORM_MAP 變位映射**：`llamas`→`llamar`、`estás`→`estar` 等
- **視覺分層高亮**：核心單字（綠色粗線）、補充單字（灰色虛線）
- **例句全詞點擊查詢**：每個單字點擊彈出字典卡片

### 變更
- lesson 預設日期從「系統今天」改為「Day 1」
