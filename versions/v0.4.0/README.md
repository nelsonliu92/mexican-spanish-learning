# v0.4.0 — 主頁週次架構 + 完整內嵌字典

**日期**：2026-09-21

## 此版本包含的檔案

| 檔案 | 大小 | 說明 |
|------|------|------|
| `index.html` | 6 KB | 主頁：週次列表、每週 7 天預覽、進度追蹤 |
| `week1.html` | 40 KB | 第一週課程：7 天課程 + 完整內嵌字典 |

## 版本摘要

### 新增功能
- **主頁導覽架構**：從單一課程頁升級為「主頁→週次→課程」架構
- **Day 精準跳轉**：主頁點選特定 Day 直接跳到該天課程
- **完整內嵌字典 (DICT)**：80+ 詞條，覆蓋所有例句中出現的單字
- **FORM_MAP 變位映射**：點擊變位形式自動查原形（如 llamas → llamar）
- **視覺分層高亮**：核心亮**：核心單字（綠色粗線）、補充單字（灰色虛線）
- **例句全詞點擊查詢**：每個詞都能點擊彈出字典卡片

### 主要變更
- 原 `index.html`（單檔 7 天）→ 改名為 `week1.html`
- 新增 `index.html` 作為週次導覽主頁
- 預設日期從「系統今天」改為 Day 1（從主頁進入時）
- URL 參數 `?day=N` 支援直接跳到指定日期

## 已知限制
- 主頁週次列表中，第二週以上顯示「即將推出」（尚未產出內容）
- 字典覆蓋範圍僅含週課程例句中的詞彙，未覆蓋測驗選項
- 語音朗讀需連網（Web Speech API）

## 回滾方式
如需回滾到上一版本（單檔架構 v0.3），請使用 `../content.json` 備份資料或連繫開發者取得先前備份。
