# v0.6.0 修改說明

## 新增：🔤 基礎發音模組

### 修改檔案
- `index.html`：單一檔案完成全部新增與修改

### 新增內容

#### 1. 首頁新增「基礎發音」入口（第一週課程之前）
- 位置：主頁最上方（作為預備課入口）
- 樣式：與「我的單字本」一致的 week-card-idx 風格
- 標題：🔤 基礎發音
- 副標：Aa-Zz · 字母表、母音子音、重音規則

#### 2. 新增 pronunciation-view（四個頁籤）

| 頁籤 | 內容 | 互動 |
|------|------|------|
| **字母表** | 27 個字母網格卡片 + CH/LL/RR 特殊說明 | 點擊朗讀字母名稱和示例單字 |
| **母音** | A/E/I/O/U 五個母音 + 雙母音 | 點擊朗讀示例 |
| **子音規則** | C/G 軟硬音、R/RR 彈舌、J/G/H 區別、B/V 同音 | 點擊示例單字朗讀 |
| **重音規則** | 母音/N/S 結尾、子音結尾、重音符號 tilde、問號驚嘆號 | 範例文字說明 |

#### 3. 新增 CSS 樣式
- `.pronunciation-tabs`：頁籤導航欄
- `.alphabet-grid`：字母表網格（手機 5 欄、大螢幕 7 欄）
- `.letter-card`：單字母互動卡片
- `.vowel-card`：母音卡片
- `.sound-rule`：子音規則區塊
- `.sound-ex-card`：發音示例卡片（可點擊朗讀）

#### 4. 新增 JavaScript 函數
- `showPronunciation()` / `showPronunciationTab(tab, btn)`：導航與頁籤切換
- `renderAlphabet()`：渲染字母表 + 特殊字母
- `renderVowels()` / `renderDiphthongs()`：渲染母音與雙母音
- `renderConsonantRules()`：渲染 5 大子音規則
- `renderAccentRules()`：渲染重音規則
- `speakAlphabet(name, example)`：連續朗讀字母名稱和示例

#### 5. 更新現有函數
- `showHome()`：增加隱藏 pronunciation-view
- `showVocab()`：增加隱藏 pronunciation-view
