# 墨西哥西語學習 App — 版本總覽

## 目錄結構

```
墨西哥西語學習App/
├── index.html          ← 當前版本主主頁
├── week1.html          ← 當前版本第一週課程
├── content.json        ← 原始課程資料（備份）
├── CHANGELOG.md        ← 版本紀錄與修改說明
├── versions/           ← 所有歷史版本備份
│   └── v0.4.0/
│       ├── index.html  ← 該版本的主頁
│       ├── week1.html  ← 該版本的課程頁
│       └── README.md   ← 該版本的修改說明
└── README.md           ← 本檔案（版本總覽）
```

## 版本命名規則

採用語意化版本 **SemVer**：`MAJOR.MINOR.PATCH`

| 位置 | 意義 | 觸發條件 |
|------|------|---------|
| **MAJOR** | 架構變革 | 單檔 → 多檔架構、新增週次頁面類型 |
| **MINOR** | 功能新增 | 新頁面、新互動模式、新週次內容 |
| **PATCH** | 修復調整 | bug 修復、UI 微調、單字資料補充 |

## 備份流程（每次修改前執行）

1. **備份**：將當前所有生產檔案複製到 `versions/vX.Y.Z/`
2. **修改**：編輯生產檔案
3. **說明**：在 CHANGELOG.md 新增一條版本紀錄
4. **交付**：提供更新後的檔案給使用者
