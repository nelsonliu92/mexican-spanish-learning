# 墨西哥西語學習 App 版本紀錄

> 📋 使用者要求：每次修改前必須先備份上一版本到 `versions/` 目錄，並建立修改說明檔。
>
> **生效日期**：2026-09-21

---

## 版本規則

- **MAJOR** (X.0.0)：架構變更（如單檔 → 多檔週次架構）
- **MINOR** (X.Y.0)：功能新增/大改（如新頁面、新互動模式）
- **PATCH** (X.Y.Z)：bug 修復、內容調整、UI 微调

---

## [v0.5.1] - 2026-09-21

### 新增功能
- **💾 進度備份與匯入**：解決 iOS Safari `file://` 模式下 `localStorage` 會在 App 重開後被清除的問題
  - 主頁新增「💾 進度備份」入口卡片
  - **匯出**：按鈕產生 JSON 備份碼（內含 `progress` + `vocab`），自動複製到剪貼簿（或由使用者手動全選複製），貼到備忘錄保存
  - **匯入**：貼上之前存的 JSON → 按「匯入進度」→ 自動恢復學習進度與單字本
  - 自製模態窗（非系統原生），規避 `file://` 模式下的剪貼簿 API 限制

---

## [v0.5.0] - 2026-09-21

### 新增功能
- **🎙️ 發音按鈕補強**：字典彈窗新增「🔊 朗讀」按鈕，點擊查詞後可直接朗讀該單字（`es-MX`）
- **📝 每日小測驗擴展為 3 題**：每 Day 從 1 題擴充為 3 題連續作答，答完自動顯示「下一題 →」，3 題全對才計入完成
- **⭐ 我的單字本**：
  - 字典彈窗新增「☆ 加入單字本 / ★ 已收藏」按鈕
  - 主頁新增「🌍 我的單字本」入口卡片（顯示收藏數量）
  - 單字本頁面支援朗讀與刪除，使用 `localStorage`（key: `mx_vocab_notebook_v1`）離線儲存
- **測驗解析強化**：每題答錯即時顯示解釋，3 題結束顯示總結（全對顯示 🎉 / 未全對提示可以再練習）

### 修復
- **第二題/第三題顯示亂碼修復**：擴充測驗題目時誤用 HTML 實體編碼（`&#191;` `&#233;` 等）放入 JS 字串，經 `esc()` 轉義後顯示為原始標記。已全部轉換為真實 Unicode 字符
- **Script Error 修復**：`LESSONS` 陣列中 `quiz:Q1`~`quiz:Q7` 未同步改為陣列格式（`[Q1_1,Q1_2,Q1_3]`），導致 `ReferenceError: Q1 is not defined`

## [v0.4.7] - 2026-09-21

### 修復
- **iPhone 離線跳轉最終方案**：將主頁與課程合併為單頁應用 (SPA)，徹底繞過 iOS `file://` 跨頁面導航限制
- **單一檔案架構**：僅需傳輸 `index.html` 一個檔案到 iPhone，主頁與七天課程內容全部內嵌
- **無縫切換**：點 Day row → JS 隱藏主頁、顯示對應對應課程；點返回 → 隱藏課程、顯示主頁
- **CSS class 隔離**：主頁與課程區塊使用獨立 class（`-idx` 後綴），避免樣式衝突

---

## [v0.4.6] - 2026-09-21

### 修復
- **iPhone 離線 Script Error 真正原因**：之前錯誤猜測是 ES6 語法或 URL query string，真正問題是 `file://` 連結導航 + 巢狀 `<a>` 結構
- **改用純 HTML `<a href>` 連結**：index.html 完全重寫為靜態 HTML，零巢狀 `<a>`
- **URL hash 標誌化**：簡化為 `#d1` ~ `#d7`，week1.html 同時支援 localStorage 備援與 URL hash
- **week1.html 返回連結**：頂部加入「← 返回主頁」
